
# Task Tracker CLI

A simple command-line task tracker written in Go. Tasks are stored in a local JSON file.

This project was built for the [roadmap.sh Task Tracker challenge](https://roadmap.sh/projects/task-tracker).

## Requirements

- Go 1.21 or newer

## Run

Clone the repository and move into its folder:

```bash
git clone https://github.com/huygiaa05/task-tracker-cli.git
cd task-tracker-cli
